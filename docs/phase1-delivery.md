## 6. 建议验收路径

1. 打开数据资产页，上传 MAT 文件
2. 进入诊断任务页新建任务
3. 绑定振动文件、可选转速文件和参数源
4. 打开任务详情页执行分析
5. 检查风险等级、主导峰值、证据摘要和结论
6. 点击确认结论，验证状态流转到已完成
